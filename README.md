# BSc CSIT Lab Reports (Semesters 2–6)

This repository is a curated collection of lab report source code for the
**BSc Computer Science & Information Technology** program at **Acharya Institute
of Higher Education (TU-affiliated)**, organized by semester.

> ⚠️ **Academic Integrity Notice:** These files are provided as a learning
> reference for prospective students and future instructors. They are **not**
> intended to be copied or submitted as your own work. Use them to understand
> concepts, debug your own programs, or as a starting point for deeper
> exploration — then write your own solutions.

## Semester Breakdown

### Semester 2

**Languages:** C++

Organized under `Semester-2/Sem 2/`:

- **`DS Labs/`** — Data Structures lab assignments (Lab 1–6)
  - Implementation of stacks, queues, linked lists, trees, graphs, sorting,
    and searching algorithms.
- **`OOP Labs/`** — Object-Oriented Programming lab assignments (Lab 3–6)
  - Classes, inheritance, polymorphism, file handling, templates.

```
Semester-2/
└── Sem 2/
    ├── DS Labs/
    │   ├── Discrete-Structure-Lab-1-main/   # Recursion, Tower of Hanoi

    │   ├── Discrete-Structure-Lab-3-main/   # Linked lists
    │   ├── Discrete-Structure-Lab-4-main/   # Stacks & queues
    │   ├── Discrete-Structure-lab-5-main/   # Trees
    │   └── Discrete-Structure-Lab-6-main/   # Graphs & searching
    └── OOP Labs/
```

### Semester 3

**Languages:** C++, VHDL

Organized under `Semester-3/Sem 3 Labs/`:

- **`Computer Architecture/`** — Digital logic design using VHDL
  - Gate-level simulations: AND, OR, NOT, NAND, NOR, XOR, XNOR
  - Combinatorial circuits: multiplexers, decoders, encoders
  - Sequential circuits: flip-flops, counters, ALUs, control units
- **`Computer Graphics/`** — C++ graphics programming (wxWidgets/Dev-C++)
  - DDA and Bresenham line drawing
  - 2D transformations (translation, rotation, scaling, clipping)
- **`DSA/`** — Data structures & algorithms
  - Linked lists, stacks, queues, trees, sorting, graph algorithms
- **`Numerical Method/`** — Numerical computation in C++
  - Root finding, interpolation, numerical integration, differential equations
- **`stats lab printout labs/`** — Statistics lab output documentation

```
Semester-3/
└── Sem 3 Labs/
    ├── Computer Architecture/      # VHDL digital logic design
    ├── Computer Graphics/           # C++ graphics algorithms
    ├── DSA/                         # Data structures & algorithms
    ├── Numerical Method/            # Numerical methods in C++
    └── stats lab printout labs/     # Statistics documentation
```

### Semester 5

**Languages:** Python, PHP, HTML/CSS

Organized under `Semester-5/`:

- **`Cryptography_Labs/`** — Cryptographic algorithms
  - Classical ciphers (Caesar, Hill, Vigenère, Playfair, Rail Fence)

  - Sorting algorithms, greedy algorithms, graph algorithms (Dijkstra, Prim, Kruskal)

- **`SAM_Labs/`** — System Analysis & Modeling
  - Queueing models, simulation (GPSS), Markov chains, Poisson processes
  - Linear programming, inventory models
- **`WebTech_Labs/`** — Web Technologies
  - HTML5, CSS3, JavaScript, PHP
  - Form handling, CRUD operations, session management

## How to Run

### C++ (Semesters 2, 3, 6)

```bash
g++ "DS lab 1 Q.1 .cxx" -o output && ./output
```

> Many files in `Semester-2` and `Semester-3` have spaces in filenames
> (preserved from original lab submissions). Quote filenames when compiling.

### Python (Semesters 4, 5)

```bash
python3 tictac.py
```

### Prolog (Semester 4)

```bash
# Install SWI-Prolog: brew install swi-prolog (macOS) or apt install swi-prolog (Linux)
swipl -q -f family.pl -g "main." -t "halt."
```

### Flex/Bison (Semester 6)

```bash
# Install Flex & Bison
flex F1_parser.l
bison -d F2_parser.y
g++ -o parser F1_parser.cpp F2_parser.tab.c
./parser < input.txt
```

### PHP (Semester 5)

```bash
# Install PHP
php Q1.php
```

## Conventions & Naming

- **File naming:** Original filenames from lab submissions are preserved
  (including spaces and inconsistent capitalization) to maintain fidelity
  with the source material. This is especially visible in `Semester-2` and
  `Semester-3`.
- **`README.md` files:** Each major lab folder may contain a `README.md`
  with lab-specific instructions or output notes.
- **Build artifacts:** `.exe`, `.o`, `.docx` output printouts, and `.vscode`
  configs have been removed to keep the repository source-only.
- **Cisco Packet Tracer:** `.pkt` files in `Semester-4/CN Labs/` require
  Cisco Packet Tracer to open.
